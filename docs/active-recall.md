# Active recall, flashcards and spaced repetition

**Active recall formats** (strongest first):
- **Free recall:** a blank page where students write everything they know about a topic, then compare against the full notes.
- **Prediction plus explanation:** predict-then-watch, then "explain why you were wrong."
- **Drawing from memory:** force diagrams, motion graphs, ray diagrams, circuits.
- **Short answer and numeric problems** with randomized values, so students can't memorize the answers.
- **Two-step questions:** the answer, then the reason. The reason exposes which misconception is behind a wrong answer.
- **Confidence-rated answers:** confident wrong answers get extra review, because correcting a confident mistake sticks best.
- **Spot the mistake:** a worked solution with a planted error.
- **Feynman technique:** explain the concept simply, and the AI tutor probes gaps.
- **"Why?" questions** (elaborative interrogation) and **self-explanation** of each step in a worked example.
- **Interleaved practice:** problem sets mixing topics, so students must choose the method.
- **Faded worked examples:** each new example leaves more steps blank.
- **Rebuilding a concept map** from memory.
- **Estimation (Fermi) questions** and **unit checks.**
- **Simulation challenges:** "set the angle so it lands on the target."
- Multiple choice is the weakest format; use it mainly to diagnose misconceptions, with distractors written from common wrong ideas.

**Flashcard styles:**
- Basic question/answer, and the reverse
- **Cloze:** one blank inside an equation or sentence
- **Symbol cards:** symbol ↔ meaning ↔ SI unit
- **Formula cards:** when the formula applies and when it doesn't
- **Graph shape:** "sketch v–t for…", then reveal
- **Image occlusion:** labels hidden on a diagram
- **Randomized numeric cards:** new values every review
- **"Why" and concept cards**
- **Mini-simulation cards:** predict before flipping
- **Typed answers:** maths input with automatic checking

**Spaced-repetition systems:**
- Leitner boxes → SM-2 → **FSRS** (★) → half-life regression → Bayesian and knowledge-tracing models for skills.
- Review modes: due queue, daily limits, interleaved sessions, cram mode before exams.
- Grading: Again / Hard / Good / Easy. Typed and numeric answers are graded automatically.
